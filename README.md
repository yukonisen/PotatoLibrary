# Potato Library for LightNovelReader

This is a [Next.js](https://nextjs.org) project repo for the tutorial.

Since my close friend NightFish and I have been polishing LightNovelReader and shipping versions for a long time, its goal has always been a multi‑source reader.

Of course, that means someone has to write data sources. I know that can be a pretty big hurdle, because programming isn’t easy for most people. You’ll need some basics — mainly Kotlin, network requests, content parsing, and a bit of Android experience.

So this repo is the web part of the tutorial. It provides a sample reading site and guides developers step by step on how to write a source for it.
This site is also my first attempt at vibe coding, and it looks like the agent understood my ideas correctly. The design itself is provided by me.

## Getting Started

We’ve already deployed it, so you don’t have to run it.

If you want to run it locally, just run:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.
